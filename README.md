## Latest: Inyon

<a href="https://inyon.abhashchakraborty.tech"><img alt="Inyon: coding agents, on your phone. The overview on a desktop and a phone, with a Codex prompt waiting for Yes, Always or No." src="asset/projects/inyon.webp" /></a>

My coding agents kept stopping to ask "can I run the tests?" while I was away from my desk, so I built them a remote. **[Inyon](https://inyon.abhashchakraborty.tech)** puts every agent running in my tmux on my phone, and one tap types the answer back into the same pane. It works with Claude Code, Codex, Gemini CLI, OpenCode, Copilot CLI and Antigravity CLI, needs no account and no server to host, and it's free.

## Open source

- **[Dokploy](https://github.com/Abhash-Chakraborty/dokploy)**: I maintain my own build of this self-hosted PaaS and run my servers on it. 184 commits and 21 releases add fleet SSH, a firewall that rolls itself back if it locks me out, an encrypted vault and restic backups with restore drills.
- **[mem0](https://github.com/Abhash-Chakraborty/mem0)**: a self-hosted memory server with an entity graph, webhooks and a one-container pgvector image, synced with upstream every week.
- **[recodehive](https://github.com/recodehive/recode-website/pulls?q=is%3Apr+author%3AAbhash-Chakraborty+is%3Amerged)**: 7 merged PRs, including Clerk sign-in, Algolia search and a fix that stopped exposing tokens in the browser.
- **[Gityzer](https://github.com/vansh-codes/Gityzer/pulls?q=is%3Apr+author%3AAbhash-Chakraborty+is%3Amerged)**: 9 merged PRs during Social Winter of Code 2025, among them the AI badge generator and SVG rendering. Second-largest contributor.
- **[Nyay Sathi](https://github.com/vikas872/nyay-sathi-clean/pull/1)**: my v2.0 upgrade moved this Indian-law assistant to agentic RAG with cited sources.
